# RNN Sentiment Analysis using PyTorch

## About the Project
This project uses a Recurrent Neural Network (RNN) built with PyTorch to perform sentiment analysis on text reviews. The goal is to classify reviews as positive or negative using deep learning and Natural Language Processing (NLP).

## Objectives
- Understand how RNNs process sequential text data.
- Preprocess text reviews for model training.
- Train a sentiment classification model using PyTorch.
- Evaluate model performance on test data.

## Technologies Used
- Python
- PyTorch
- NumPy
- Pandas
- JupyterLab

## Project Workflow
1. Load the dataset.
2. Preprocess and tokenize text.
3. Convert text into numerical sequences.
4. Build the RNN model.
5. Train the model.
6. Evaluate predictions and calculate accuracy.

## Model Evaluation
The model is evaluated using a test dataset and classification accuracy.

## How to Run
1. Clone this repository:
   ```bash
   git clone https://github.com/raghuvanshidhyanvi-ui/RNN-Sentiment-Analysis-pytorch.git
   ```
2. Navigate to the project folder.
3. Install the required dependencies:
   ```bash
   pip install torch numpy pandas jupyterlab
   ```
4. Open JupyterLab:
   ```bash
   jupyter lab
   ```
5. Open and run the notebook.
